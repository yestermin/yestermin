# 웹소설 — 로맨스/현대물 연재 공간

이 폴더는 연재용 로맨스/현대물 원고와 설정 자료를 모아둔다.

## 폴더 구조

- `STYLE.md` — 문체·형식 기준. 새 회차를 쓰기 전에 먼저 읽는다.
- `템플릿/` — 새 작품을 시작할 때 복사해서 쓰는 캐릭터 시트, 세계관 시트, 플롯 아웃라인 양식.
- `작품명/` — 작품별 폴더. 회차 원고와 그 작품의 설정 문서(캐릭터·세계관·타임라인)를 함께 둔다.

새 작품을 시작하면 `템플릿/`을 `작품명/`으로 복사해 채우고, 회차는 그 안에 `001_회차제목.md` 형식으로 쌓는다.

## 설정 관리

작품 하나에 설정 문서 세 개를 기본으로 둔다.

- `캐릭터.md` — 인물별 이름·나이·직업·외모·성격·말투·관계
- `세계관.md` — 시간적/공간적 배경, 이 세계에서만 통하는 규칙
- `타임라인.md` — 회차별로 이미 밝힌 정보와 아직 안 밝힌 떡밥을 기록. 설정 오류(나이·날짜·관계 모순)를 막는 용도다.

회차를 쓸 때마다 타임라인부터 확인하고, 쓴 뒤에는 새로 밝힌 정보를 추가한다.
