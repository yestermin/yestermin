# 복수는 취향입니다 — 작업팀 운영

## 고정 팀

| 팀 | 책임 | 산출물 |
| --- | --- | --- |
| 소설팀 | 본편 회차 집필, 인물 감정선과 사건 진행 | 4,500~5,500자 회차 원고 |
| 유튜브팀 | 확정 원고의 이미지 컷 기반 각색 | 낭독 원고, 컷 ID, 시나리오별 프롬프트 |
| 검수팀 | 소설·영상·이미지 프롬프트 독립 검수 | 분량·정합성·컷 대응 보고 |
| 팀장 | 배치 계획, 설정 통합, 검수 반영, 최종 저장 | 갱신된 타임라인·캐릭터·최종 커밋 |

## 순서

1. 팀장이 회차 비트와 배치 범위를 지정한다.
2. 소설팀과 유튜브팀이 겹치지 않는 파일을 동시에 작업한다. 유튜브팀은 미확정 사건을 단정하지 않는다.
3. 소설팀 초안과 유튜브팀 각색을 각각 검수팀에 전달한다.
4. 팀장이 검수 지적을 반영하고 설정 문서를 갱신한다.
5. 팀장이 관련 파일만 커밋하고 GitHub에 push한다.

## 이미지 영상 원칙

유튜브팀의 영상 소스는 정지 이미지다. 인물 외형·의상·소품·장소는 `유튜브/복수는_취향입니다/이미지/비주얼바이블.md`를 따른다. 이미지 생성에는 글자와 로고를 넣지 않고, 편집에서 자막을 합성한다. 생성 영상 동작은 사용하지 않는다.

## 불확정 사실 처리

이정훈의 생사, 태오의 1막 말미 행방, 익명 문자 발신자, 강 회장의 직접 지시, 박승만의 지시 여부는 확정 전까지 정황·추측으로만 쓴다. 검수팀은 침묵이나 간접 증거를 자백으로 바꾸는 문장을 별도 지적한다.
