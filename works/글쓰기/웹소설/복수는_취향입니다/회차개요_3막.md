# 3막 회차별 비트 — 진실 폭로 (36~55화)

2막 마지막 기자회견에서 차미란의 이름이 공개된 직후부터, 은채가 자료의 출처와 공개 절차를 통해 강 회장의 프레임을 되돌리는 과정을 다룬다. 3막의 중심은 폭로 자체가 아니라 누가 무엇을 언제 보았는지 분리해 확인하는 일이다. 태오의 고백은 관계의 감정선을 움직이지만, 그 고백만으로 강 회장의 직접 지시나 차미란의 현재 상태를 확정하지 않는다.

| 회차 | 핵심 비트 | 회차 끝 훅 |
| --- | --- | --- |
| 36 | 은채와 태오가 재회 직후 서로의 행동을 따로 확인한다. 태오는 은채 정보를 강 회장에게 넘긴 범위만 인정하고 납치·감금·직접 지시는 확정하지 않는다 | 차미란 이름이 나온 기자회견 자료의 원본 보관처가 과거 회계팀 외부 서버로 표시됨 |
| 37 | 은채가 차미란 이름이 등장한 화면 자료의 출처·편집 경로·문서 번호를 추적한다. 생사·현재 행방·직접 지시는 보류한다 | 문서 원본의 최초 등록자가 차미란 본인이 아닌 제3의 계정으로 남아 있음 |
| 38 | 강 회장 측이 ‘은채의 사적 복수’ 프레임을 선점한다. 은채는 공개 조사, 원본 보존, 관련자 선택권 회복을 동시에 제안한다 | 독립 조사 요청서에 차미란의 옛 서명이 아닌 새로운 전자서명이 찍힘 |
| 39 | 은채가 이사회에 원본 보존과 독립 조사 안건을 상정한다. 윤 이사는 조건부로 동의하고 박승만은 절차를 흔든다 | 보존 명령 직전 원본 서버에 누군가 원격 접속함 |
| 40 | 태오가 자신이 넘긴 은채 정보의 목록과 시점을 제출한다. 일부 정보가 강 회장 보고서에 변형되어 있음을 확인한다 | 보고서의 변형 문장을 만든 계정이 소라의 행사기획 계정과 연결됨 |
| 41 | 소라는 계정 공유 사실은 인정하지만 강 회장 지시는 부인한다. 은채는 소라의 거래 제안을 증언이 아닌 조건부 자료로 다룬다 | 소라가 보관한 원본 봉투에 차미란의 퇴사일과 다른 날짜가 적혀 있음 |
| 42 | 차미란 옛 동료가 보관함 기록을 제공한다. 기록에는 차미란의 마지막 출근과 문서 반출 시각만 남아 있다 | 반출 확인 서명이 차미란 필체와 다르게 보임 |
| 43 | 필체 감정과 서버 로그를 병행한다. 은채는 유사성을 인정하되 작성자 확정을 피한다 | 감정기관에 이미 같은 문서의 선행 의뢰가 있었다는 사실이 드러남 |
| 44 | 강 회장이 은채의 친정 회사를 불법 승계의 출발점으로 몰아간다. 은채는 원본 계약서 전체와 이사회 의사록을 맞세운다 | 의사록의 한 페이지가 공식 보관본과 외부 배포본에서 다름 |
| 45 | 김 변호사가 보관본 차이를 법적 보존 절차로 전환한다. 윤 이사가 조사 범위 확대에 표를 던진다 | 조사 대상 서버의 관리자 권한이 하루 전 바뀜 |
| 46 | 태오가 아버지의 보고 라인에 들어갔던 사실을 공개하고 은채 앞에서 선택의 결과를 감당한다 | 태오가 삭제하지 못한 음성 메모에 차미란 이름이 아닌 ‘첫 번째 회계사’가 언급됨 |
| 47 | 은채는 익명 제보와 공개 조사 사이의 안전장치를 만든다. 유리안의 자료를 제3자 보존기관에 맡긴다 | 보존기관 접수증에 이정훈 사건과 같은 자문사 코드가 표시됨 |
| 48 | 소라가 강 회장에게서 분리돼 자신이 가진 자료를 공개하려 한다. 은채는 소라의 동기와 자료를 분리해 검증한다 | 소라의 자료에는 강 회장을 보호하는 편집 흔적도 함께 남아 있음 |
| 49 | 조사 중간보고서가 이사회에 제출되고, 강 회장의 배임 정황이 ‘조사 필요 사유’로 공식 기록된다 | 강 회장이 긴급 주주총회 소집을 먼저 공고함 |
| 50 | 3막 끝. 은채가 원본·사본·정황을 공개한 가운데 이사회는 독립 조사 착수를 의결한다. 강 회장과 소라가 마지막 반격을 준비한다 | 은채 명의의 계좌에서 친정 회사 인수대금 일부가 다시 발견됨 |
| 51 | 강 회장이 은채를 공모자로 지목하고 임시 주주총회의 의제를 바꾸려 한다 | 은채의 서명이 있는 듯한 비밀합의서가 등장함 |
| 52 | 은채는 합의서의 전자서명 인증서와 작성 시각을 대조한다. 태오는 자신의 인증 수단이 사용됐음을 알게 된다 | 인증서가 보관된 기기에는 소라의 접근 기록이 남아 있음 |
| 53 | 소라가 접근 기록은 인정하지만 문서 작성은 부인한다. 은채는 둘의 진술을 교차검증한다 | 강 회장 측 핵심 증인이 차미란의 현재 소재를 안다고 주장함 |
| 54 | 증인의 말은 위치를 특정하지 못하고, 과거에 본 서류와 전언만 제공한다. 은채는 생사와 행방을 확인하지 않은 채 공개한다 | 공개 직전 이정훈 원본 노트의 마지막 페이지가 복원됨 |
| 55 | 3막 후속부. 복원된 페이지가 강 회장의 직접 지시가 아닌 승인 구조와 책임 분산 방식을 가리킨다. 은채는 최종 주주총회로 향한다 | 은채의 친정 회사 인수대금 계좌에 마지막 입금자가 강 회장이 아닌 은채 자신으로 기록됨 |

## 운영 원칙

- 3막은 36~55화로 운영하며, 1차 배치는 36~38화다. 이후 배치는 세 회차 단위로 초안을 작성하고 팀장 통합·검수를 거친다.
- 차미란의 생사, 현재 행방, 직접 지시, 현장 출석과 발언 여부는 확인 자료가 나오기 전까지 확정하지 않는다. 이름·서명·퇴사 기록은 서로 다른 검증 항목으로 취급한다.
- 태오가 은채 정보를 강 회장에게 넘긴 범위는 본인의 진술과 기록으로 확인할 수 있지만, 그것이 납치·감금·모든 후속 조작의 지시였다고 확대하지 않는다.
- 문서의 원본·사본·정황·해석을 분리한다. 필체 유사성, 로그 공백, 침묵, 간접 전달은 단독으로 자백이나 직접 지시가 되지 않는다.
- 은채의 복수는 공개 망신보다 원본 보존, 독립 조사, 관련자의 선택권 회복을 우선한다. 강 회장 측의 프레임에 반응하되 같은 방식의 단정으로 맞서지 않는다.
- 로맨스 감정은 재회, 배신 인정, 거리 두기, 선택의 책임을 통해 압박한다. 태오와 은채의 관계 회복 여부는 3막에서 성급히 확정하지 않는다.
- 회차 원고는 제목·본문·이미지 자리·이미지 생성 프롬프트를 포함하고 4,500~5,500자 범위를 지킨다. 끝에는 다음 조사나 관계 변화를 여는 훅을 둔다.
