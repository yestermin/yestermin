# 4막 회차별 비트 — 파국과 결말 (51~60화)

3막에서 독립 조사 착수가 의결된 뒤, 강 회장과 소라가 은채를 공모자로 몰아 최종 주주총회를 흔드는 과정을 다룬다. 은채는 계좌·합의서·전자서명·증언을 원본·사본·정황으로 나누어 맞서고, 태오는 아버지의 편에 남는 대신 자신의 과거 선택과 공개 범위를 스스로 결정한다. 차미란의 생사와 현재 행방은 확인되지 않은 정보로 남기며, 결말은 확인 가능한 책임과 선택의 회복에 둔다.

| 회차 | 핵심 비트 | 회차 끝 훅 |
| --- | --- | --- |
| 51 | 강 회장이 은채를 공모자로 지목하고 임시 주주총회의 의제를 바꾸려 한다 | 은채의 서명이 있는 듯한 비밀합의서가 등장함 |
| 52 | 은채가 합의서의 전자서명 인증서와 작성 시각을 대조하고, 태오는 자신의 인증 수단이 사용됐음을 알게 된다 | 인증서가 보관된 기기에 소라의 접근 기록이 남아 있음 |
| 53 | 소라가 접근 기록은 인정하지만 문서 작성은 부인한다. 은채가 두 진술과 로그를 교차검증한다 | 강 회장 측 핵심 증인이 차미란의 현재 소재를 안다고 주장함 |
| 54 | 증인의 말은 위치를 특정하지 못하고 과거에 본 서류와 전언만 제공한다. 은채는 생사·행방을 확인하지 않은 채 조사 자료로 공개한다 | 공개 직전 이정훈 원본 노트의 마지막 페이지가 복원됨 |
| 55 | 복원된 페이지가 강 회장의 직접 지시가 아닌 승인 구조와 책임 분산 방식을 가리킨다. 은채는 최종 주주총회 자료를 정리한다 | 친정 회사 인수대금 계좌의 마지막 입금자가 강 회장이 아닌 은채 자신으로 기록됨 |
| 56 | 은채가 자신의 계좌 기록을 포함한 전체 거래 원장을 독립 조사기관과 주주에게 제출한다. 태오는 인증 수단의 사용 경위를 진술하기로 한다 | 주주총회 전날 은채 명의의 추가 합의서가 발견됨 |
| 57 | 추가 합의서의 원본·사본·작성 시각을 대조하고, 소라가 과거 행사기획 계정으로 파일을 열람한 사실을 확인한다 | 합의서 마지막 조항의 수신자가 은채가 아닌 태오로 표시됨 |
| 58 | 태오가 수신자로 기록된 문서와 자신의 기억을 분리해 공개한다. 은채는 관계 회복을 조건으로 진술을 요구하지 않는다 | 태오가 강 회장에게 직접 묻지 못했던 질문을 주주총회에서 공개하겠다고 선언함 |
| 59 | 임시 주주총회에서 은채가 원본 보존·독립 조사·관련자 선택권의 결과를 설명하고, 강 회장과 소라의 반박을 자료별로 대조한다 | 의결 직전 강 회장 측 의결권 일부의 위임장이 무효 처리됨 |
| 60 | 은채가 독립 조사 착수와 경영권 전환 절차를 확정하고, 강 회장과 소라는 확인된 책임의 범위 안에서 퇴장한다. 태오와 은채는 재결합을 서두르지 않고 대등한 관계의 조건을 합의한다 | 처음 이혼 통보를 받았던 회장실에 이번에는 대표로 앉은 은채가 다음 기록을 연다 |

## 운영 원칙

- 4막은 51~60화로 운영하며, 세 회차 단위 초안·팀장 통합·별도 검수 순서를 유지한다.
- 계좌 기록, 비밀합의서, 전자서명, 위임장과 증언은 원본·사본·정황·해석으로 분리한다. 은채 명의 기록이 발견되어도 즉시 자작극이나 무죄를 확정하지 않는다.
- 차미란의 생사·현재 행방·현장 출석·발언은 확인되지 않은 상태를 유지하고, 이름이나 문서가 결말의 단정으로 사용되지 않게 한다.
- 강 회장과 소라의 몰락은 확인된 절차와 책임 범위로 묘사한다. 직접 지시가 확인되지 않은 사건을 두 사람의 자백으로 확대하지 않는다.
- 태오와 은채의 관계는 재결합 여부보다 사과, 진술, 공개 범위, 선택권을 서로 존중하는 대등한 관계의 조건을 먼저 확정한다.
- 회차 원고는 제목·본문·이미지 자리·이미지 생성 프롬프트를 포함하고 4,500~5,500자 범위를 지킨다. 유튜브 각색은 16:9 정지 이미지와 팬·줌·페이드만 사용한다.
