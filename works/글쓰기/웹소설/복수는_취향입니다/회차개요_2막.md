# 2막 회차별 비트 — 반격과 재회 (16~35화)

1막 마지막의 불확정 상태를 유지하면서 은채가 태오의 행방을 추적하고, 태오가 처음으로 집안의 질서에서 벗어나 은채의 편에 서는 과정을 다룬다. 납치·사망·문자 발신인의 정체는 조기에 확정하지 않는다.

| 회차 | 핵심 비트 | 회차 끝 훅 |
| --- | --- | --- |
| 16 | 은채가 태오 사무실과 감사팀 기록을 확인하고 경호팀의 이동 경로를 추적한다 | 태오가 마지막으로 접속한 장소가 회장실이 아님이 드러남 |
| 17 | 정하윤·김 변호사와 비공식 수색. 은채는 태오가 남긴 자료의 암호를 찾는다 | 자료 안에 은채를 겨냥한 가짜 증거가 있음 |
| 18 | 은채가 가짜 증거를 역이용해 태오의 위치를 좁힌다 | 태오에게서 짧은 음성 파일 도착 |
| 19 | 음성 파일의 배경음으로 장소 추정. 소라는 약혼 발표를 강행하려 한다 | 태오가 은채의 이름을 부르다 녹음이 끊김 |
| 20 | 은채와 소라의 공개 대면. 팔찌의 출처를 둘러싼 심리전 | 소라가 은채의 어머니에 관한 오래된 사실을 흘림 |
| 21 | 은채가 어머니의 유품 기록을 확인하고 복수의 목적을 재정의한다 | 유품 보관 기록에 강 회장 측 서명이 있음 |
| 22 | 태오의 내부 접근 기록을 추적하던 은채가 감사팀의 조작 정황을 발견한다 | 감사팀 보고서 작성자가 박승만과 연결됨 |
| 23 | 박승만을 압박하지만 그는 운전기사와의 관계를 부인한다 | 운전기사의 계좌에서 다른 발신처 발견 |
| 24 | 유리안이 안전한 장소에서 추가 자료를 보내온다 | 이정훈 노트의 빈 페이지에 숨은 좌표가 있음 |
| 25 | 좌표의 장소에서 차미란의 옛 동료를 만난다 | 차미란이 자발적으로 사라진 것이 아닐 수 있음 |
| 26 | 태오의 위치와 차미란 기록이 같은 법인으로 연결된다 | JS경영자문과 과거 자문사의 공통 인감 확인 |
| 27 | 은채가 이사회 안건을 수정해 공개 조사 범위를 넓힌다 | 윤 이사가 조건부 찬성 의사를 밝힘 |
| 28 | 소라가 은채의 친정과 어머니 유품을 공격 소재로 삼는다 | 은채의 아버지 회사 관련 새 고소 예고 |
| 29 | 은채가 공개 대응 대신 증거 보존을 택한다. 태오의 과거 선택을 재평가한다 | 태오가 남긴 두 번째 음성에 사과가 담김 |
| 30 | 은채가 태오를 구하기 위한 협상안을 만들지만 강 회장은 거절한다 | 강 회장이 태오가 있는 장소를 알고 있다는 암시 |
| 31 | 소라와 강 회장의 이해관계가 어긋나기 시작한다 | 소라가 혼자 은채에게 거래를 제안 |
| 32 | 은채와 소라가 일시적으로 같은 자료를 추적한다 | 소라가 약혼 발표를 뒤집을 증거를 제시 |
| 33 | 태오가 스스로 탈출할 기회를 만들고 은채에게 단서를 보낸다 | 단서가 은채의 다이어리 원본 보관 장소를 가리킴 |
| 34 | 은채가 이사회와 언론에 공개할 자료를 최종 정리한다 | 강 회장이 먼저 기자회견을 예고 |
| 35 | 2막 끝. 은채와 태오가 직접 재회하되, 둘 사이에 증거와 배신의 문제가 남는다 | 강 회장의 기자회견 화면에 차미란의 이름이 등장 |

## 운영 규칙

- 집필팀은 3화 단위로 초안을 낸다.
- 유튜브팀은 같은 배치의 원고가 확정된 뒤 이미지 컷 시나리오를 만든다. 동시 진행이 필요한 경우 확정되지 않은 사건은 추정·정황으로만 말한다.
- 검수팀은 소설 원고와 영상 원고를 따로 읽고, 팀장은 타임라인·캐릭터·프롬프트 ID를 통합한다.
