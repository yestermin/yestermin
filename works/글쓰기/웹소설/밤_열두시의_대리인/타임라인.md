# 타임라인 — 1막 첫 배치

| 회차 | 확인된 사건 | 미해결 질문 |
| --- | --- | --- |
| 001 | 박명희 명의로 접수된 통화에서 성문동 화재 사건 번호와 검은 봉투 보전 요청을 듣는다. 문밖 방문자는 강도현의 음성과 같은 목소리를 낸다. | 발신자·방문자의 정체, 박명희 명의 번호를 사용한 경로 |
| 002 | 문을 열지 않은 윤서가 기록을 확인한다. 로컬 녹음은 남아 있지만 서버 전송 기록에는 7분 공백이 있다. 현관 투입구로 전달된 검은 봉투가 책상 위에 놓인다. | 서버 공백 원인, 봉투 전달자와 사본 출처 |
| 003 | 봉투 속 위임장 사본에 아버지의 서명과 사망 사흘 뒤 날짜가 있다. 하단에는 도현의 검사 시절 도장이 보인다. | 실제 서명자·날인자, 문서 작성 시점과 도장의 기능 |
| 004 | 과거 녹취와 통화 음성의 호흡을 대조하지만 생존·동일인 여부를 확정하지 않는다. 새 통화가 윤서의 현관과 책상 위치를 묻는다. | 현재 위치를 아는 경로, 실시간 통화인지 재현 음성인지 |
