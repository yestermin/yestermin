# 배치 기록

## 1막 첫 배치 — 001~004화

- 001화: 파일럿 확정. 서윤서가 박명희 명의의 전화에서 강도현의 목소리를 듣는다. 현관문은 열지 않았으며 방문자 신원은 미확정이다.
- 002~004화: 연재 원고·10분 영상 각색·독립 검수 완료. 최종 판정 통과.
- 002화 본문 4,872자, 003화 5,183자, 004화 5,054자. 제목·끝 훅·줄바꿈 제외, 공백 포함.
- 영상 실제 발화 3,427자. B01~B12 12컷, A01~A08 포함 누적 20컷. 실제 이미지 생성 및 음성 녹음은 미수행.
- 검수 지적: 서버 공백 시간 표현, 필적의 시각 표현, 001 영상의 닫힌 서랍 상태, 녹음 저장과 문밖 발화 순서를 수정하고 재검수했다.

## 1막 두 번째 배치 — 005~008화

- 005~008화 원고와 03 유튜브 각색·C01~C12 프롬프트를 완성했다.
- 원고 본문: 005화 5,384자, 006화 4,780자, 007화 4,845자, 008화 4,856자.
- 영상 발화: 3,329자(문단 연결 방식 3,412자), 시간표 00:00~10:00.
- 누적 이미지컷: A01~A08, B01~B12, C01~C12 총 32컷.
- 독립 검수 지적 3건을 수정했다. 005의 날짜 표기와 미확정 범위, 007의 화재 전날 밤 전달 시점, C03의 허가 후 열린 상자 촬영 상태를 통일했다.
- 최종 판정: 통과.
- 분량 기준: 001화는 파일럿 1,500~2,000자, 002화부터 본문 4,500~5,500자.
- 영상 기준: 001화 5분 A01~A08, 002~004화 10분 B01~B12. 실제 낭독 속도로 최종 러닝타임을 조정한다.

## 연속성 기준

- 통화 로컬 녹음과 서버 전송 기록은 구별한다. 서버의 공백이 로컬 파일까지 지워졌다는 의미는 아니다.
- 검은 봉투의 전달 경로와 내용의 진위를 구별한다.
- 서명·날짜·도장의 사본만으로 실제 서명자나 지시자를 확정하지 않는다.
- 음성의 유사성만으로 강도현의 생존을 확정하지 않는다.
- 윤서의 아버지 사망일 뒤 작성된 위임장이 다음 조사 중심이다.
