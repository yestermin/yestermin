# 팀 구성 — 복수는 취향입니다

회차 작업은 팀 단위로 진행한다. 역할을 나누고, 팀장이 최종 승인·커밋한다.

## 역할

- **팀장** — 회차별 작업을 배정하고, 집필팀 초안과 검수팀 리포트를 받아 최종 원고를 확정한다. `타임라인.md` 갱신과 git 커밋·push까지 책임진다.
- **집필팀** — `플롯.md`의 해당 화 개요, `캐릭터.md`, `세계관.md`, `타임라인.md`(밝혀진 정보·떡밥)를 바탕으로 회차 초안을 쓴다. `STYLE.md` 기준(분량 4,500~5,500자, 시점, 클리셰 운용)을 지킨다.
- **검수팀** — 집필팀과 분리된 별도 담당. 초안을 완성된 결과물로 취급하지 않고 다음 기준으로 감사한다:
  - `STYLE.md` 위반(분량, 시점 혼용, 작가의 말 혼입, 요약형 결말 등)
  - `캐릭터.md`·`세계관.md`와의 모순(나이·말투·관계·장소 설정 불일치)
  - `타임라인.md` 위반(이미 밝힌 정보의 재설명, 떡밥 회수 누락·조기 회수, 날짜/숫자 모순)
  - 문장 품질(반복 표현, 늘어지는 문단, 클리프행어 약화)
  - 검수팀은 초안을 고치지 않는다. 문제를 지적만 하고, 반영 여부는 팀장이 정한다.

## 처리 순서

1. 팀장이 해당 화 범위를 `플롯.md`에서 확인하고 집필팀에 배정한다.
2. 집필팀이 초안을 작성한다.
3. 검수팀이 초안을 감사하고 지적 사항을 보고한다.
4. 팀장이 지적 사항을 반영해 원고를 확정하고, `타임라인.md`를 갱신한 뒤 커밋·push한다.
