# 복수는 취향입니다 — 정지 이미지 컷목록

이미지 프롬프트 담당자 전달용. 총 **67개 고유 컷**: T01~T04 4컷, S01~S10 10컷, E01~E15 15컷, A01~A24 24컷, B01~B14 14컷. 같은 영상 안에서 컷 반복 사용 가능. 아래 ID는 시나리오 화면 지시와 일치한다.

## 공통 제작 기준

- 기본 16:9 가로 화면. 현대 한국 기업·호텔 배경의 사실적 시네마틱 드라마. 동일 인물의 얼굴·머리·의상·장신구를 모든 컷에서 유지한다. 컷마다 새로운 인물처럼 생성하지 않는다.
- 모든 컷은 **정지 이미지**다. 편집은 팬·줌·페이드만 사용한다. 걷기·입 모양·손동작·문 열림·화면 스크롤 등의 실제 움직임이나 생성 영상이 필요하지 않도록, 사건 전후의 멈춘 순간을 그린다. 효과음과 대사는 별도 오디오다.
- 서류·문자·기사의 정확한 글자는 생성 이미지에 맡기지 않는다. 여백이나 비어 있는 화면을 확보하고 후반 작업에서 정지 텍스트로 합성한다. 텍스트 등장도 페이드만 쓴다. 표의 핵심 문구는 후반 합성용이며 이미지 생성 지시가 아니다.
- 시간은 영상 재생 위치이지 사건의 연도가 아니다. 과거 인수·결혼·이혼의 구체 연도나 ‘몇 년 전’ 문구를 이미지에 넣지 않는다. 모든 영상은 현재 이혼 통보부터 시작한다.
- 이정훈·차미란의 감금·사망, 강 회장의 납치 지시, 문자 발신인, 미끼별 전달 대상은 그리지 않는다. 확인되지 않은 인과관계를 실사 재현으로 확정하지 않는다.
- 원전 11화의 미끼 배분 모순은 생략한다. A15에서는 ‘서로 다른 미끼 중 하나에 반응한 운전기사와 유출 정황’만 보여준다. 특정 미끼 문서와 특정 수신자를 선으로 연결하지 않는다.

## 재사용 및 전달 메모

- A05는 5분대 취임 재검토 장면에도 반복한다. S06은 강 회장 회유 대사 구간에서 오래 유지해도 된다. 각 컷 안에서 얼굴·손·서류를 다르게 크롭해 팬·줌할 수 있다.
- 제목 카드·기사·문자·문서 글자는 위 이미지에 합성하거나 검정 배경으로 페이드한다. 별도의 서사 이미지 컷을 추가하지 않아 총수는 53컷으로 유지한다.
- 프롬프트 담당자는 ID를 파일명 접두어로 유지한다. 시나리오 작성자는 발화 라벨을 `N:`, `은채:` 등 한 줄 단위로 통일한다. 대괄호 지시문과 제작 기준은 낭독 대상이 아니다.
