# 복수는 취향입니다 — 20분 2막 기자회견과 재회 각색

## 제작 기준 · 낭독 제외

- 원전: 2막 회차 비트 034~035화. 은채가 공개 패키지를 정리해 강 회장의 기자회견을 먼저 선점하고, 은채와 태오가 직접 재회한 뒤 증거와 배신의 문제를 남긴다. 마지막 기자회견 화면에는 차미란의 이름이 등장하지만, 그 이름만으로 생사·행방·발언 여부를 확정하지 않는다.
- 목표 러닝타임 20분, 낭독 발화 목표 6,000~7,000자(공백·문장부호 포함, 화자 라벨·지시문 제외). 시간 블록은 편집 목표이며 무음·효과음·화면 여백은 발화와 별도로 배정한다.

- 주 소스는 정지 이미지 J01~J14 총 14컷이다. 편집은 느린 팬·느린 줌·페이드만 사용하고, 인물·문·휴대폰 화면의 실제 움직임은 만들지 않는다.
- 공개 패키지는 원본, 사본, 정황 자료를 별도 묶음으로 보관하고 설명한다. 사본은 원본을 대신하지 않으며, 정황은 직접 지시나 사실 확정으로 바꾸지 않는다.
- 강 회장이 기자회견을 먼저 예고했다는 사실과 은채가 공개 자료를 먼저 배포하려는 선택은 구분한다. 강 회장의 직접 지시, 기자회견의 전체 목적과 내용은 확정하지 않는다.
- 태오와의 재회는 이 원고의 현재 장면에서 두 사람이 직접 마주 섰다는 사실만 확인한다. 태오가 그 전까지 어디에 있었는지, 어떤 상태였는지, 누가 데려갔는지, 어떻게 빠져나왔는지는 말하지 않는다.
- 태오가 건네거나 설명하는 자료도 원본·사본·정황을 구분한다. 태오의 말은 당사자 진술이며, 그 자체로 자료의 진위나 배신의 전모를 확정하지 않는다.
- 문서·휴대폰·기자회견 화면의 글자와 로고는 이미지에 생성하지 않고 후반 정지 자막으로 합성한다. 한 화면에는 핵심 문장 하나만 둔다.

## 편집·검수 메모

- J01~J07은 034화의 공개 패키지 정리와 강 회장 기자회견 선점이다. 원본·사본·정황을 별도 묶음으로 유지하고, 기자회견의 내용·강 회장 직접 지시·자료 작성자를 확정하지 않는다.
- J08~J11은 035화의 은채·태오 직접 재회와 증거 검토다. 재회는 현재 장면의 대면 사실만 확인하며, 태오의 이전 위치·상태·경로·생사를 만들지 않는다. 태오의 진술과 사본은 원본과 분리한다.
- J12~J14는 기자회견 화면에 `차미란` 이름이 등장하는 장면과 끝 훅이다. 이름의 등장만으로 차미란의 생사·현재 행방·기자회견 참석·발언 여부를 확정하지 않으며, 강 회장 직접 지시도 확정하지 않는다.
- 모든 컷은 정지 이미지 한 장이며 편집은 느린 팬·느린 줌·페이드만 사용한다. 문서·휴대폰·모니터·기자회견 화면의 글자·숫자·로고·워터마크는 생성하지 않고 후반 정지 자막으로 합성한다.
- 낭독 발화 글자 수는 화자 라벨·대괄호 지시문·제목·제작 메모·후반 자막 지시를 제외해 집계한다.
