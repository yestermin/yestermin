- 016화는 15화 말미의 닫힌 사무실과 불명확한 태오의 행방에서 출발해 보안 기록과 회장실 외 접속 장소를 확인한다. 2막 16화 비트와 정합하다.
- 017화는 비공식 수색, 운전기사의 제보, 태오 계정으로 보이는 접속, 은채를 겨냥한 가짜 증거 발견으로 이어진다. 2막 17화 비트와 정합하다.
- 018화는 가짜 증거를 세 경로로 흘려 반응을 확인하고, 태오처럼 들리는 음성 파일을 받는 지점에서 끝난다. 2막 18화 비트와 정합하다.
- 세 회차 모두 계정 사용 주체, 운전기사의 진술, 음성의 주체와 발신 경로를 추정 또는 정황으로 남긴다. 이정훈·차미란의 생사와 행방을 새로 확정하지 않는다.
- 각 회차에 본문 이미지 자리와 별도 프롬프트가 있으며, 장면 자체는 정적 장면 중심이다.

### 수정 반영 항목

1. **016화 27행 — 강제 이동을 사실처럼 말함**
   - 근거: `"태오 씨가 끌려갔는데, 여기서 자료가 오기를 기다리라고요?"`
   - 조치: `태오 씨의 행방이 끊겼는데`로 교체해 이동 방식의 확정을 제거했다.

2. **016화 209행 — 태오를 데려간 사람을 확정함**
   - 근거: `태오를 데려간 사람들은 회장실로 향하지 않았다.`
   - 조치: `태오의 행방과 연결된 일행이 회장실로 향했다는 기록은 없었다`로 교체해 행위 주체를 확정하지 않았다.

3. **018화 153행 — 발신자를 확정함**
   - 근거: `발신자는 강태오.`
   - 조치: `표시된 발신 계정은 강태오가 쓰던 계정과 같았다`로 교체하고 후속 유보 문장을 유지했다.

4. **018화 250행 — 삽화 프롬프트가 발신자 표시를 요구함**
   - 근거: `화면 옆에는 강태오의 발신자 표시와 짧은 파일 아이콘이 보이고`
   - 조치: `화면 옆에는 발신자명 없는 짧은 파일 아이콘이 보이고`로 교체했다. 유튜브 B13 프롬프트는 기존에도 발신자·파일명·장소를 표시하지 않도록 되어 있어 추가 수정은 없다.

## 2. 유튜브 시나리오 검수

### 통과

- 낭독 발화는 화자 라벨과 제작 지시문을 제외해 **6,078자**로 측정되어 목표 6,000~7,000자에 들어온다.
- B01~B14가 시나리오에 모두 사용된다.
- 제작 지시는 정지 이미지 14컷을 기반으로 하고, 컷 내부 움직임을 만들지 않으며 편집 움직임을 느린 팬·줌·페이드로 제한한다.
- 발신자, 태오의 위치·상태, 음성의 주체는 대사와 내레이션에서 유보한다. `…은채야.`라는 짧은 음성만 정황으로 사용한다.
- 납치·감금·폭행·사망을 장면이나 확정된 사건으로 재현하지 않는다. 불안은 닫힌 문, 빈 복도, 기록 불일치, 통화 단절, 짧은 음성으로 표현한다.

## 3. 이미지 프롬프트 검수

### 통과

- `이미지/05_2막_초반각색_프롬프트.md`에 `## B01`부터 `## B14`까지 14개 프롬프트가 있다.
- 시나리오의 B01~B14와 1:1로 대응한다.
- 모든 프롬프트가 3840×2160, 16:9, 정지 이미지, 자막 후반 합성, 글자·로고·워터마크 배제 원칙을 공유한다.
- 인물 외형, 의상, 색감, 카메라 톤이 공통 규칙으로 고정되어 캐릭터 일관성을 유지한다.
- B13은 무문자 휴대폰 화면과 발신자·파일명·장소 미표현을 명시하고, B14도 음성 출처와 태오의 상태를 확정하지 않는다.

## 4. 컷목록 검수

- `시나리오/컷목록.md`의 2막 초반 표에 B01~B14가 모두 포함되어 있다.
- 총 컷 수 표기도 `T01~T04 4컷 + S01~S10 10컷 + E01~E15 15컷 + A01~A24 24컷 + B01~B14 14컷 = 67개 고유 컷`으로 일치한다.
- 각 B컷에 시간 블록, 장면, 후반 합성·편집 방식이 기록되어 시나리오와 연결된다.
