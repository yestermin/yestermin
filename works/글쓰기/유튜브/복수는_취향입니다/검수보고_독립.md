## 2. 완성 통지 후 검수 절차

사용자 추가 지시에 따라 이미지 프롬프트는 아래 4개 파일로 시나리오별 분리 저장되어야 한다. 비주얼바이블은 별도 공통 문서로 유지한다. README의 기존 단일 `컷별프롬프트.md` 안내보다 이 추가 지시를 우선하며, 완성본에서 README·컷목록의 링크도 실제 분리 파일과 일치하는지 확인한다.

| --- | --- |
| 1분 예고 | 이미지/01_1분_예고_프롬프트.md |

1. 1·5·10·20분 원고, 컷목록, 비주얼바이블, 위 4개 프롬프트 파일을 모두 처음부터 끝까지 읽는다. 완성 통지된 파일의 수정 시각·해시를 기록해 검수 대상 버전을 식별한다.
2. 원작 나머지 회차와 설정 문서를 대조하여 사건 출처·인물 선택의 원인·시간 순서·증거의 전달 경로를 확인한다. 사전 열람 3개 회차만으로 전체 원작 충실성을 판정하지 않는다.
3. 시나리오 ↔ 컷목록 ↔ 해당 시나리오의 분리 프롬프트 파일 대응표를 모든 컷 ID별로 작성한다. 파일별 컷 수와 합계를 기록하고 총 53개의 고유 컷과 프롬프트를 확인한다. 누락·중복 정의·미사용·미정의 참조·다른 시나리오 파일로의 잘못된 배치를 구분한다. 원고 간 의도된 재사용은 중복 정의와 구분하며, 재사용 컷도 각 해당 파일에서 독립 실행할 수 있어야 한다.
4. 각 컷의 프롬프트 블록 하나만 복사해도 단독 실행 가능한지 전수 확인한다. ‘위와 동일’, ‘바이블 참조’, 다른 파일·앞 컷 참조, 인물 이름만으로 생략된 외형 등 외부 문맥 의존을 점검한다. 화면 속 주요 인물과 장소·소품의 고정 정보, 필요한 화면 비율·화풍·텍스트 처리 조건이 개별 프롬프트에 충분히 들어 있어야 한다. 공통 서문이나 바이블에만 필수 조건을 두고 개별 컷에서 빠뜨린 경우 수정 필요로 기록한다. 이는 문서상 독립 실행성 검수이며 실제 이미지 생성 시험은 수행 범위에 포함하지 않는다.
5. 인물별 외형·머리·연령대·의상·액세서리와 장소별 배치·재질·조명을 바이블 및 모든 컷에서 대조한다. 시간·장면에 따른 합리적인 의상 변화와 같은 장면 내 불일치를 구분한다. 팔찌는 형태·재질·장식·착용자·착용 손목을 특히 확인한다. 원작에 없는 디자인은 제작 설정으로 허용하되 원작 사실로 주장하지 않는다.
6. 다이어리·서류 사진·휴대폰 등 반복 소품, 회장실·호텔 대표실·본가·복도의 구별, 인물 위치와 시간대의 연속성을 확인한다. 15화 오후 두 시 장면과 원작 삽화의 해 질 녘 표현도 무조건 동일시하지 않는다.
7. 발화만 따로 추출하고 원문과 대조한 뒤 분량 및 실제 길이의 현실성을 계산한다.
8. 지적마다 파일·행 또는 컷 ID, 문제 문구, 원작 근거, 영향, 구체적인 수정 요구를 기록한다. 검수자가 원고를 직접 고치지 않는다.

## 3. 발화 분량과 러닝타임 계산 기준

- 내레이션·실제 인물 대사·명시적으로 낭독하는 문자만 포함한다. 화자명, 컷 ID, 제목, 시간표, 화면·음향·연기 지시, 비낭독 화면 자막, 마크다운 표식은 제외한다. 문자 화면과 낭독이 함께 있어도 발화는 실제 녹음 횟수만 센다.
- 괄호 속 내용은 일괄 삭제하지 않고 발화인지 지시인지 문맥으로 판별한다. 불명확한 부분은 임의 확정하지 않고 해당 구간과 분량 영향을 별도 기록한다.
- 발화 내부 공백과 문장부호는 포함하되 추출 과정의 줄바꿈·연속 공백은 단일 공백으로 정규화한다. 숫자·영문·약어가 많으면 실제 읽는 방식이 문자 수 추정에 미치는 영향을 명시한다.
- README 가정인 분당 공백 포함 300~350자를 사용한다. 발화 문자 수가 N이면 발화 예상 시간은 N/350~N/300분. 실제 낭독 실측값과 혼동하지 않는다.
- 무음·효과음 단독 구간은 별도 합산한다. 발화와 겹치는 음악·효과·정지 이미지 노출 시간은 다시 더하지 않는다. 호흡·극적 멈춤은 중복 계상하지 않고 가정과 범위를 기록한다.
- 전체뿐 아니라 구간별 발화량과 배정 시간을 비교한다. 정지 이미지 컷 수가 많거나 시간표가 목표에 맞는 것만으로 실제 길이를 인정하지 않는다.

## 5. 최종 확인

- 1분·5분 원고의 화면 지시에 컷 ID를 보완했다. 1분은 T01~T04 4컷, 5분은 S01~S10 10컷, 10분은 E01~E15 15컷, 20분은 A01~A24 24컷으로 각 시나리오 프롬프트와 1:1 대응한다.
- 발화량은 각각 269자, 1,587자, 3,479자, 7,000자다. 실제 러닝타임은 낭독 속도·호흡·무음·효과음에 따라 녹음 후 재측정한다.
- 모든 영상 소스는 정지 이미지다. 팬·줌·크롭·페이드만 사용하며 걷기·입 모양·문 열림·화면 스크롤 같은 생성 동작은 요구하지 않는다.
- 문서·기사·문자·서명·로고의 글자는 이미지 생성에서 제외하고 후반 정지 자막으로 합성한다.
- 원작의 11화 미끼 배분 모순은 20분 각색에서 특정 미끼와 수신자를 연결하지 않는 방식으로 제거했다.
- 이정훈·차미란의 실물, 감금·사망, 강 회장의 납치 지시, 태오의 이후 행방, 익명 문자 발신자는 이미지로 확정하지 않았다.

실제 이미지 파일은 아직 생성하지 않았다. 이미지 생성 전에는 각 프롬프트로 샘플 컷을 만들어 얼굴·의상·팔찌·장소 레퍼런스를 고정하고, 바이블과 다른 결과만 재생성한다.
