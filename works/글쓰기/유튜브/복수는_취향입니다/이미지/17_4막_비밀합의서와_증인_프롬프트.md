# 복수는 취향입니다 — 4막 1차 배치 이미지 프롬프트(P01~P14)

## 공통 프롬프트

- 3840x2160, 16:9 가로, 사실적 시네마틱 한국 기업 스릴러 드라마, 정지 이미지 한 장.
- 모든 컷은 사건 전후의 멈춘 순간이다. 실제 움직임·입 모양·화면 스크롤·손 동작을 생성하지 않고 편집에서 느린 팬·줌·페이드만 사용한다.
- 이미지 안에 읽을 수 있는 글자·숫자·문서 내용·회사명·로고·워터마크·계좌번호를 생성하지 않는다. 핵심 문구와 시간은 후반 자막으로 합성한다.
- 서은채: 남색 팬츠수트, 아이보리 블라우스, 검정 머리 로우번, 절제된 표정.
- 강태오: 차콜수트, 피로하고 망설이는 표정.
- 한소라: 아이보리 코트, 와인색 원피스, 금색 팔찌. 팔찌는 은채 어머니 유품과 같은 디자인.
- 정하윤: 베이지재킷, 단정하고 실무적인 인상.
- 김 변호사: 네이비수트, 회색넥타이, 안경과 서류가방을 컷마다 동일하게 유지.
- 강 회장은 직접 지시 장면으로 표현하지 않는다. 차미란의 실물·생사·행방·출석·발언도 표현하지 않는다. 차미란 이름은 후반 자막으로만 제한적으로 표시한다.

## 전달 규칙

- P01~P14는 시나리오와 1:1로 연결하고, 파일명·후반 자막·편집 순서의 ID를 변경하지 않는다.
- 화면에 문서의 실제 글자나 숫자를 생성하지 않는다. 합의서·전자서명·시각·로그는 빈 문서와 무지 카드로 표현하고 자막은 후반 합성한다.
- 차미란의 소재 주장은 증인의 말과 자료 봉투로만 표현한다. 차미란의 얼굴, 현재 장소, 생사, 출석, 발언을 시각화하지 않는다.
- 강 회장의 직접 지시는 어떤 컷에서도 재현하거나 확정하지 않는다.
