## 사용 규칙

- 모든 이미지는 3840x2160, 16:9 정지 이미지로 생성한다. 실제 움직임은 만들지 않고 편집에서 느린 팬·줌·페이드만 사용한다.
- 이미지 안에 글자·로고·워터마크·읽을 수 있는 문서·계정명·코드·음성 파형 문자를 생성하지 않는다. 필요한 문구는 후반 자막으로 합성한다.
- 차미란의 생사·행방·출석·발언을 암시하는 얼굴, 실루엣, 현재 위치를 만들지 않는다.
- 강 회장의 직접 지시 장면을 만들지 않는다. 관리자 권한 변경, 태오의 보고 라인, 자문사 코드 일치는 확인할 사실과 미확정 해석을 분리한다.
