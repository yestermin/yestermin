## 사용 규칙

- 모든 이미지는 3840x2160, 16:9 정지 이미지로 생성한다. 실제 움직임은 만들지 않고 편집에서 느린 팬·줌·페이드만 사용한다.
- 이미지 안에 글자·로고·워터마크·읽을 수 있는 문서·계좌번호·주주명단·회사명은 생성하지 않는다. 필요한 문구는 후반 자막으로 합성한다.
- 소라 자료의 공개 사실과 공개 동기, 자료의 원본성은 별도 층위로 유지한다.
- 강 회장을 보호하는 편집 흔적은 문장 생략·순서 변경·접근 기록의 방향으로만 표현한다. 편집자와 강 회장의 직접 지시는 미확정이다.
- 배임 정황은 독립 조사가 필요한 사유로만 표현한다. 유죄·손해액·최종 수익자를 이미지로 확정하지 않는다.
- 은채 명의 계좌는 계좌 명의와 실제 사용자·지시자·수익자를 분리한다. 계좌번호나 실제 거래 상대방을 생성하지 않는다.
- 차미란의 생사·행방·출석·발언을 얼굴·실루엣·현재 장소로 표현하지 않는다.
