# 복수는 취향입니다 — 정지 이미지 비주얼 바이블

## 적용 범위

현대 서울을 배경으로 한 한국 재벌 복수 로맨스. 모든 영상은 16:9 실사 시네마틱 정지 이미지 중심이다. 한 컷에는 한 시점의 결정적 순간만 담고, 줌·팬·페이드·문자·대사 자막은 편집에서 처리한다. 실제 이미지 생성 전 사용하는 제작 명세이며 현재 생성된 레퍼런스는 없다.

원작 기준: `원작_1차보관/캐릭터.md`, `세계관.md`, 001~015화. 컷의 사건·순서는 `../시나리오/컷목록.md`를 따른다. T01~T04(예고), S01~S10(요약), E01~E15(1화), A01~A24(1막), 총 53컷은 서로 다른 편집안이다. 같은 사건은 같은 인물·세트·소품 레퍼런스를 재사용한다.

## 공통 화면 규칙

- 3840×2160 권장, 16:9 가로 화면, 사진처럼 자연스러운 피부결, 절제된 영화적 명암, 미세한 필름 그레인. 현실적인 한국 성인 배우 외형, 특정 실존 배우를 모사하지 않는 가상 캐스팅.
- 먹색·남색·회색을 중심으로 저채도 색보정. 피부는 중립색, 금색은 팔찌와 작은 실내 조명에 한정한다. 밤에도 눈과 표정을 식별할 수 있는 약한 보조광을 둔다.
- 대화는 50mm 눈높이, 감정은 85mm 가까운 얼굴, 공간은 35mm 중경·전경, 소품은 85mm 근접을 기준으로 한다. 렌즈 수치는 시각적 지침이다.
- 아래 18%는 편집 자막을 놓을 단순한 배경으로 확보한다. 얼굴·팔찌·증거 소품은 이 영역을 피한다. 가장자리 8% 안전 여백을 두어 느린 확대·이동에 대비한다.
- 생성 이미지에는 한글·영문·숫자·서명·도장 글자·워터마크·회사 로고·자막·말풍선을 넣지 않는다. 문서는 뒷면/빈 종이, 기기 화면은 무문자 단색 면으로 표현하고, 모든 내용은 편집 자막으로 올린다. 읽히지 않는 가짜 글자도 생성하지 않는다.
- 합성 콜라주·분할 화면·동작 연속 프레임 금지. 감정은 시선·손끝·거리로 드러내고, 과장된 악역 웃음이나 로맨틱 포옹으로 관계를 앞당기지 않는다.

2. **각도·의상**: 확정 얼굴을 실제 입력 이미지로 첨부하여 3/4 얼굴 `CHAR-EC_threequarter.png`, 전신 `CHAR-EC_full.png`를 각각 만든다. 얼굴만 비슷한 새 캐스팅을 고르지 않는다. 전신에서 의상색·가르마·팔찌 손목을 확인한다. 한 장에 여러 패널을 합치지 않는다.
3. **소품 마스터**: PROP-BR→DI→NB→PH→DOC→CASE 순으로 만든다. 팔찌는 단품 참조와 CHAR-SR을 함께 첨부해 왼손목 착용본을 확인한다. 실제 문서 글자는 만들지 않는다.
4. **장소 마스터**: LOC-CHAIR→HOME→GATE→CAR→LOBBY→CEO→BOARD→MEET→COR→TAEO→SUITE→STUDY→DINE 순으로 빈 세트 전경을 만든다. 재사용할 배치가 먼저 확정되어야 인물을 넣는다.
5. **기준 장면**: 확정 컷목록의 첫 회장실·팔찌·세단·대표실·이사회·스위트룸 컷을 먼저 만든다. 인물 얼굴/전신, 해당 장소, 핵심 소품 레퍼런스를 각각 첨부한다. 2인 이상이면 `첨부 1=은채, 2=태오`처럼 입력 순서와 역할을 명시하고 얼굴 혼합을 금지한다.
6. **나머지 53컷**: 승인된 동일 마스터를 계속 첨부한다. 이름이나 참조 ID를 프롬프트에 쓰는 것만으로 동일인물이 보장되지 않는다. 도구의 참조 이미지 입력/인물 일관성 기능을 실제 사용한다. 시드는 지원할 때 기록하는 보조값이며 얼굴 고정 수단을 대신하지 않는다.
7. **부분 수정**: 잘못된 손·팔찌·의상은 확정 얼굴 및 기존 컷을 함께 참조하여 해당 영역만 수정한다. 전면 재생성 후 닮은 얼굴을 채택하지 않는다. 같은 사건의 T/S/E/A 컷은 가능하면 승인 원본의 재크롭을 사용하되 얼굴과 자막 안전영역을 지킨다.

프롬프트 코드블록은 단독 복사 가능하도록 모든 스타일·외형·의상·장소·구도·제외사항을 반복한다. 코드블록 안에 첨부할 참조 ID를 명시한다. ID는 제작용 별칭이고 생성 이미지에 쓰는 글자가 아니다.

## 원작 충돌·미확정 사항 보고

- **의상 각색**: 원작 002·006·015화 등의 은채 코트/코트 주머니와 캐릭터 시트의 화려해지는 옷차림은 사용자 고정안과 다르다. 영상은 남색 팬츠수트·아이보리 블라우스·검정 로우번으로 통일하고 휴대폰은 손에 든다. 원작은 수정하지 않는다.
- **소라 색상**: 003화의 흰 코트는 사용자 지정 아이보리 코트로 통일한다. 와인색 원피스·금색 팔찌의 세부 디자인·착용 손목은 영상용 고정 설정이다.
- **원본 보관**: 008화는 방에서 다이어리 3권을 꺼내면서 동시에 원본이 김 변호사 보관처에 있다고 한다. 초반 짐 정리 이후의 조사 화면은 태블릿으로 통일한다.
- **시간선**: 원작의 현재 이혼/3년 전 이혼, 과거 인수 연도 혼선은 README 각색 기준대로 처리한다. 회상에 다른 나이의 얼굴이나 혼인 상태를 단정하는 소품을 추가하지 않는다.
- **011화 미끼 배정**: 다이어리 이동 정보를 고재민에게 주었다가 운전기사 쪽 정보였다고 서술하는 불일치가 있다. 영상은 세 갈래 미끼와 운전기사 방문이라는 관측 결과를 보여주고, 세부 수신자 배정 및 직접 지시자는 자막에서도 임의 확정하지 않는다.
