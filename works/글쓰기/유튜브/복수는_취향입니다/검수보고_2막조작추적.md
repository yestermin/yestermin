### 022화 연결과 2막 비트

021화 마지막의 `강 회장실 대리` 직함과 도장·유품 보관 기록이 022화 첫머리의 확대 도장 사진과 강 회장실 대리 직함으로 바로 이어진다. 근거는 021화 257~293행, 022화 3~21행이다.

022화는 조작된 감사 보고서의 시간 불일치와 삭제 주석을 먼저 제시하고(022화 11~89행), 회장실 템플릿·`psm.office` 계정·상무실 출력본으로 박승만 쪽 접점을 넓힌다(022화 93~169행). 마지막의 `감사팀_대필_임시계정`과 외부협업 임시계정은 다음 화로 넘어갈 추적 고리를 만든다(022화 269~309행). 023화는 이 접점을 대면 확인과 계좌 기록으로 확장하고, 024화는 유리안 자료와 빈 페이지 압흔으로 새로운 질문을 열어 2막의 조사 확대와 중간 훅을 유지한다.

### 박승만 직접 지시 여부

직접 지시는 확정하지 않는다. 022화는 `psm.office` 계정이 사용됐다는 사실과 박승만이 보고서 내용을 알고 있었던 정황을 구분하고, 계정 사용자와 직접 지시자를 특정할 수 없다고 명시한다(022화 107~121행, 163~169행, 263~297행). 023화에서도 박승만의 진술은 부인으로 남고, 세 자료와 접속 경로를 분리해서 보도록 한다(023화 25~33행, 221~245행). 따라서 검수 기준의 ‘박승만 직접 지시 미확정’을 충족한다.

### 이정훈 생사·차미란 행방·좌표 장소

024화는 좌표처럼 보이는 문자열을 제시하지만 마지막 숫자가 흔들리고, 좌표를 지도에 넣어도 실제 장소라는 근거가 없다고 명시한다(024화 101~161행). 이후에도 `좌표 후보 A — 실제 장소·작성자·전달자 미확정`, `태오 접근 기록과의 시간 중첩 — 관련성 미확정`으로 유지한다(024화 143~161행, 197~205행).

이정훈의 생사는 `아직 살아 있는지 모르겠습니다`라는 전달 문장과 질문 상태로 남고, 이정훈이 좌표를 썼다는 사실도 확정하지 않는다(024화 167~183행, 263~279행). 차미란의 행방이나 생사 역시 좌표와 연결될 가능성만 질문으로 남아 있다(024화 183~195행). 마지막의 `누군가가 ... 같은 화면을 보고 있었다`도 접속 장치 정황일 뿐, 접속자 정체나 태오의 위치·상태를 확정하지 않는다(024화 243~287행).

## 3. 유튜브 검수

### 발화 분량

`시나리오/07_2막_조작추적각색.md`의 발화는 화자 라벨과 지시문을 제외하고 **6,694자**다. 기준인 6,000~7,000자를 충족한다. 시나리오 자체도 라벨·지시문·제목·제작 메모를 제외해 집계하도록 명시한다(3~7행, 219~225행).

### D01~D14 1:1 대응

시나리오, 이미지 프롬프트, 컷목록 세 파일에 각각 D01부터 D14까지 14개 ID가 모두 존재한다. 각 ID의 역할과 시간대는 다음처럼 대응한다.

- D01~D04: 보고서 시간 순서 변경, 작성자·전달 경로·박승만 쪽 결재 묶음의 접점
- D05~D07: 박승만의 운전기사 관계 부인, 별도 계좌 발신처
- D08~D11: 유리안 추가 자료, 이정훈 노트 빈 페이지와 압흔
- D12~D14: 세 자료의 분리 보관, 좌표 후보와 장소 미확정 훅

시나리오의 화면 전환은 D01→D02부터 D13→D14까지 순서가 끊기지 않고, 컷목록은 각 ID에 한 행씩 대응한다(컷목록 140~157행). 프롬프트도 각 ID별 `Production ID`를 하나씩 제공한다(프롬프트 15~97행). 따라서 ID 누락이나 고아 컷은 확인되지 않는다.

### 이미지·편집 기준

공통 프롬프트가 모든 결과를 `3840×2160, 16:9 horizontal` 정지 이미지로 고정한다(프롬프트 3~8행). 같은 규칙에서 걷기·문 열기·스크롤·연속 동작·생성 영상을 금지하고 느린 팬·느린 줌·페이드만 허용한다(프롬프트 8행). 시나리오도 정지 이미지와 느린 팬·줌·페이드만 사용하도록 명시한다(시나리오 5~13행). D01~D14 컷목록의 후반 편집 지시도 팬·줌·페이드 범위 안에 있다(컷목록 144~157행).

## 4. 정황 유지와 확정 금지 검수

### 감사팀 조작

보고서의 삭제 주석, 시간 순서 불일치, 회장실 템플릿, 상무실 계정과 임시계정은 조작 가능성을 보여주는 정황으로 제시된다. 022화는 `계정이 사용됐다는 것은 ... 박승만이 직접 키보드를 눌렀다는 뜻은 아니`라고 선을 긋고(022화 107~113행), 시나리오도 작성자와 박승만 사이 접점은 확인하되 직접 지시는 미확정으로 둔다(시나리오 30~45행, 219~224행).

### 별도 계좌 발신처

023화는 운전기사 계좌에 `세진물류 정산계정`으로 표시된 입금을 제시한 뒤, 법인 표기와 실제 입금 요청 발신처가 다를 수 있음을 밝힌다(023화 157~181행, 257~305행). 별도 발신처가 박승만·소라·JU그룹 계열사에 붙지 않고, 실제 발신자와 목적도 확인되지 않은 상태로 남는다(023화 221~245행, 289~321행). 시나리오와 컷목록도 동일하게 명의·실제 발신자·자금 목적을 분리한다(시나리오 102~117행, 컷목록 149~150행).

### 유리안 자료와 빈 페이지 좌표

유리안 자료는 위치를 밝히지 않는 추가 전송으로 처리되며, 유리안의 안전 여부나 발신 경로를 확정하지 않는다(024화 21~41행, 59~69행). 빈 페이지는 글자가 아니라 압흔과 좌표 후보로만 제시되고, 장소·작성자·전달자·이정훈의 생사·차미란의 행방은 미확정이다(024화 77~95행, 109~161행, 177~195행). 시나리오 D08~D14와 프롬프트 공통 규칙도 같은 제한을 반복한다(시나리오 119~170행, 188~224행; 프롬프트 57~104행).

납치·감금·사망·시신·태오의 위치나 상태·발신자 정체를 확정하는 문장이나 이미지 지시는 확인되지 않았다. 시나리오 제작 기준이 이를 직접 금지하고, 프롬프트와 컷목록도 해당 인물과 장소를 화면에서 배제한다(시나리오 9~13행, 219~224행; 프롬프트 11~13행, 57~97행; 컷목록 151~157행).

## 5. 수정 제안

필수 수정은 없다. 현재 원고와 각색본은 검수 기준을 충족하므로 원고·시나리오·프롬프트·컷목록을 수정할 필요가 없다.

선택적으로 후반 자막을 제작할 때만 다음을 유지한다.

1. 024화의 좌표 숫자는 원문 내 후보 단서로만 사용하고, 이미지 생성 단계에서는 프롬프트와 컷목록의 지시대로 숫자·지도·지명·핀을 넣지 않는다.
2. 박승만, 별도 계좌 발신처, 유리안 자료, 빈 페이지 좌표를 한 화면의 단일 범인 도식으로 합성하지 않는다. 현재 D12~D14의 자료 간격과 미확정 자막을 그대로 유지한다.
3. 최종 낭독본에서도 `정황`, `가능성`, `미확정`, `후보`라는 판단 보류 표현을 삭제하지 않는다.

이번 검수에서 수정한 원고 파일은 없으며, 본 보고서만 작성 대상으로 삼았다.
