## 통과 확인

- 005~008은 각각 005 성문동 현장 → 006 계좌 거래와 두 번째 통화 → 007 재희의 원본 전달 증언과 화재 관련 발언 → 008 공식 기록·개인 보안회선·대리인 요청 순서로 원문 연결이 유지된다.
- 서윤서 중심 3인칭 제한 시점은 유지된다. 다른 인물의 속마음을 사실처럼 직접 서술하지 않고, 표정·말·행동에 대한 윤서의 관찰과 불확실성으로 처리한다.
- 006 본문은 계좌 이체·사망 확인 시각·통화 속 자기소개를 분리하고, 007 본문은 재희의 증언·가족에게 전해진 말·확인되지 않은 내용을 나눠 기록한다. 008 본문은 확인된 사실·개인적 추정·증언을 공식 기록 안에서 분리한다.
- 001 영상 기존 지적 1~4는 실제 파일에서 해소됐다. 002는 로컬 녹음과 서버 전송 공백을 분리했고, 003은 필적을 시각적 유사성으로 고쳤으며, A06은 닫힌 잠금서랍과 미확인 봉투 위치를 유지한다. A06 통화 종료 후 저장 → A07 문밖 발화 → A08 저장 완료 녹음기 순서도 맞다.
