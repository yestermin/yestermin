# 《밤 열두 시의 대리인》 독립 검수 — 1막 002~004

- 검수일: 2026-10-01
- 상태: 팀장 02 완성 통지 후 최신 소설·영상 제작 문서 독립 최종 검수 완료. **최종 판정: 통과.**
- 소설 001~004 전체를 읽고 회차 연결, 서윤서 중심 제한 시점과 감정, 단서의 확인 범위, 생존·신원·문서 진위·법적 책임의 미확정 표현을 대조했다. 아래에는 확인된 문제만 기록한다.
- 분량 측정: 회차 제목과 `## 끝 훅` 이후 전체를 제외하고 본문 양끝을 정리한 뒤 CR/LF를 제거했다. 내부 공백과 문장부호는 포함했다. 최신 002 4,872자 / 003 5,183자 / 004 5,054자. 모두 4,500~5,500자 범위 안이다. 001은 연결 대조용 파일럿으로 별도 취급했다.
- 검수자는 이 보고서만 작성하며 원고·영상·기존 보고서를 수정하지 않는다.

## 최종 검수 근거

001~004 소설 전체, 01·02 시나리오, 01·02 이미지 프롬프트 전체, 최신 컷목록, 비주얼 바이블·캐릭터·README를 직접 대조했다. 영상팀의 별도 보고서는 독립 집계 이후 읽었으며, 그 판정을 근거로 삼지 않았다. 실제 이미지·음성 생성물은 제출 범위에 없으므로 이번 통과는 원고와 영상 제작 문서에 대한 판정이다. 600초는 편집 시간표이며 실제 녹음 길이를 확인한 수치는 아니다.

### 발화량 직접 집계

02 시나리오의 12개 `**발화**` 영역만 추출했다. 제목·화자 라벨·근거·화면·연출·제작 지시를 제외하고 내부 공백과 문장부호를 포함했다.

- 사용자가 지정한 줄바꿈 제외 방식: 줄바꿈을 새 공백으로 치환하지 않고 제거하면 **3,446자**다. 본문에 쓰인 따옴표는 문장부호로 포함한 값이다. 대사 표시용 곡선 큰따옴표까지 제외하면 **3,390자**다. 어느 방식도 3,000~3,500자 범위를 벗어나지 않는다.
- 영상팀 표기 방식도 별도로 재현했다. 대사 표시용 곡선 큰따옴표만 제외하고 각 컷의 비어 있지 않은 발화 문단을 한 칸 공백으로 연결한 뒤 컷별 길이를 합하면 **3,427자**다. 본문 안의 작은따옴표는 유지하며 컷 사이에 추가 공백을 넣지 않는다. `시나리오/02_발화집계.txt`의 12행 및 별도 보고서의 컷별 수치와 일치한다.

### 컷·프롬프트·원문 대응

- 시나리오와 이미지 프롬프트는 각각 A01~A08 8개, B01~B12 12개이며 컷목록에는 같은 순서의 20개 ID가 중복 없이 존재한다. 02의 12개 구간은 각 50초, 00:00~10:00까지 공백·중복 없이 연결된다.
- B01~B12의 독립 코드 블록을 모두 읽고 외형·규격 조건을 확인했다. 각 블록에 서윤서 29세 한국 여성·검은 단발·왼손 검지 화상·어두운 셔츠와 재킷, 사무실 설정, 3840x2160·16:9·정지 이미지, 팬·줌·페이드, no readable text / no logo / no watermark가 들어 있다. 문서와 화면은 읽을 수 없는 추상 표식으로 제한한다. 강도현 얼굴·사진·회상 얼굴 금지와 장갑 안의 화상 처리도 명시한다. 태오는 원문 등장 시점에만 얼굴 없는 뒷모습으로 배치한다.
- B01~B04는 방문자 이탈 → 복도 영상 → 투입구 봉투 → 로컬 녹음 존재·문밖 음성 미녹음 → 서버 전송 기록 공백 → 수령 기록 후 책상 이동 순서를 유지한다. 수정된 002의 공백 시간대 로컬 녹음 표현과 끝 훅도 반영한다.
- B05~B08는 위임장 사본 → 아버지 이름과 옛 주소 → 화재일 3월 17일 대비 3월 20일 → 대표의 진위·제출 경로 확인 요구 → 003에서 처음 열린 잠금서랍의 수첩 비교 → 사본 하단 검사 강도현 도장 순서다. 생활비 봉투와 검은 전달 봉투를 구별한다. 사흘 뒤 날짜와 도장이라는 003 끝 훅의 단서가 함께 보존된다.
- B09~B12는 출입 확인 후 태오 도착 → 원본 보존과 비교용 사본 → 과거 녹취 비교 → 음성·호흡 유사 및 동일인·생존 판단 불가 → 아침·낮·귀가·저녁·다음 자정 → 마지막 위치 질문 순서다. 004 끝 훅의 질문은 원문과 일치하며 후속 답이나 새 침입 사건을 추가하지 않는다.
- 소설은 서윤서 중심 제한 시점을 유지한다. 아버지의 필적·날짜 앞에서 흔들리고 답할 사람이 필요해 목소리에 기대는 감정과 기록의 한계를 구분한다. 영상도 이를 확정 사실로 바꾸지 않는다. 전달자·전화 상대 신원, 서명·도장 진위, 생존과 법적 책임의 미확정 상태가 유지된다.

## 수정 재확인

- 팀장의 수정 완료 통지 후 해당 원고, 001 시나리오 A06~A08, 001 이미지 프롬프트, 컷목록을 다시 대조했다.
- 지적 1 해결: 002의 성문동 발화는 “서버 전송 기록이 비어 있는 시간대의 로컬 녹음”으로 수정됐다.
- 지적 2 해결: 003은 “두 이름의 마지막 획이 비슷하게 보였다”로 수정됐다.
- 지적 3 해결: 001 A06 화면은 닫힌 잠금서랍이며, 검은 봉투의 위치는 아직 확인하지 못했다고 명시한다.
- 지적 4 해결: A06 통화 종료 후 저장 → A07 문밖 발화 → A08 저장을 마친 녹음기 순서다. A08 발화는 문밖 음성이 파일에 없고 유사성은 기억에만 남았다고 명시한다. 동시 발화도 재도입되지 않았다. 최신 컷목록 A08도 “저장을 마친 녹음기”로 수정돼 시나리오·프롬프트와 일치한다.

## 최초 지적 기록 — 아래 인용은 수정 전 내용

### 1. 002화 — 통화 시각과 전송 공백의 선후 표현 충돌

- 위치: `002_일곱_분의_공백.md` 85행, “서버에 남지 않은 구간으로 들어가기 직전, 남자는 성문동이라는 이름을 입에 올리고 있었다.”
- 근거: 같은 회차의 마지막 정상 요청은 23시 59분 59초, 다음 요청은 00시 07분 00초다. 001에서는 자정에 전화가 울리고 접수·박명희 확인·칠 분 언급 뒤 성문동 사건 번호가 나온다. 따라서 성문동 발화는 이미 전송 공백 시간대 안에 있고, 그 공백에 들어가기 직전의 발화로 설명할 수 없다.
- 문제: 로컬 녹음 재생 위치와 서버 전송 공백의 시간 경계를 혼동시키는 문장이다. 공백 진입 전이라는 시간 관계를 재확인할 필요가 있다.

### 2. 003화 — 필적 비교 장면의 감각 어휘 불일치

- 위치: `003_검은_봉투의_위임장.md` 111행, “두 이름의 끝이 비슷하게 들렸다.”
- 근거: 위임장과 수첩을 나란히 놓고 마지막 획·획의 겹침·이름 사이 간격을 육안으로 비교하는 장면이다. 이름을 발음하거나 듣는 동작은 없다.
- 문제: 필적의 시각적 유사성을 설명하는 자리에서 청각 표현이 사용돼 단서의 종류가 순간적으로 흐려진다. 어휘 확인 필요.

### 3. 기존 001 영상 A06 — 열린 서랍의 잔여 화면 지시

- 위치: `시나리오/01_5분_파일럿각색.md` 99행, “반쯤 닫힌 기록 서랍”. 같은 컷 103행의 “검은 봉투를 꺼내지 않은 채”도 함께 확인 필요.
- 근거: 소설 001에서는 잠금서랍을 바라보고 열쇠를 쥘 뿐 서랍을 열지 않는다. 서랍을 여는 것은 소설 003이다. 현재 A06 이미지 프롬프트는 “닫힌 잠금서랍”을 지정한다. 소설 002의 검은 봉투는 현관 투입구 아래에서 발견된다.
- 문제: 열린 서랍 속 검은 봉투의 직접 묘사는 삭제됐지만, 시나리오 화면에 반쯤 열린 상태가 남아 원작 및 프롬프트와 충돌한다. “꺼내지 않은 채”는 아직 위치를 확인하지 않은 검은 봉투를 이미 보관 중인 소품처럼 읽히게 할 수 있다.

### 4. 기존 001 영상 A07→A08 — 녹음 저장과 문밖 발화 순서 불일치

- 위치: `시나리오/01_5분_파일럿각색.md` A07에서 문밖 남자가 말한 다음, A08 129행에 “서윤서는 파일을 저장했다.”가 배치된다. A08 화면과 이미지 프롬프트도 저장 중인 녹음기를 지정한다.
- 근거: 소설 001은 통화 종료 → 녹음 저장 및 파일명 지정 → 문밖 남자 발화 순서다. 소설 002는 “문밖 방문자의 말은 들어 있지 않았다. 이미 저장을 마친 뒤였다.”라고 이를 다음 회차의 단서 한계로 사용한다.
- 문제: 영상 순서는 저장이 문밖 발화 뒤에 이뤄진 것으로 보여, 다음 회차에서 문밖 음성을 녹음으로 비교할 수 없는 이유와 충돌한다. A08이 앞선 저장 장면의 회상이라는 표기도 없다. 동시 발화 문구는 현재 삭제돼 있으며, 이 항목은 동시 발화의 재발이 아니라 저장 순서의 잔여 문제다.

## 02 준비본 보류 이력 — 종료

최초 확인 당시 02는 원고 대기 준비본이므로 판정을 보류했다. 팀장 완성 통지를 받은 뒤 최신 완성본을 직접 검수해 위 최종 판정으로 갱신했다. 준비본의 빈 발화나 미작성 항목을 결함으로 판정한 이력은 없다.
