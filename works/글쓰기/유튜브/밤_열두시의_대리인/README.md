# 《밤 열두 시의 대리인》 유튜브팀

소설팀의 웹소설 001화 「대리인의 첫 밤」을 각색한 약 5분 분량 이미지컷 중심 영상 패키지다. 이 파일럿은 총 24부작 3막 중 1막 1화에 해당한다. 영상은 정지 이미지를 느린 팬·줌·페이드로 연결하고, 낭독과 효과음으로 장면의 빈틈을 채운다.

## 제작 기준

- 정지 이미지 8컷, A01~A08
- 모든 컷은 3840x2160, 16:9 가로
- cinematic realistic Korean mystery romance
- 이미지 안의 읽을 수 있는 글자·로고·워터마크 금지
- 편집은 느린 팬·줌·페이드 중심
- 낭독 대사는 약 5분 기준 1,500~2,000자

## 02화 10분 패키지

- [02 각색](시나리오/02_10분_공백과_위임장각색.md): 원작 002~004 전체 원문을 읽고 순서대로 압축, 실제 발화 공백 포함 3427자.
- [02 이미지 프롬프트](이미지/02_10분_공백과_위임장_프롬프트.md): B01~B12 독립 복사용 12개.
- [컷목록](시나리오/컷목록.md): B01~B12, 00:00~10:00 연속 시간표.
- [02 검수보고](검수보고_02.md): 집계 방식과 원문 대응 확인.
- 매 컷 서윤서 29세·검은 단발·왼손 검지 화상, 나이트라인 사무실, 3840x2160 16:9 정지 이미지, 팬·줌·페이드, no readable text/logo/watermark 명시.
- 로컬 녹음 존재와 서버 전송 기록 7분 공백을 구분. 방문자는 떠나며 봉투의 투입구 전달은 002에서 확인하되 전달자 신원은 미확정. 서랍은 003의 수첩 확인 단계에서 열린다.
- 강도현 얼굴 공개 금지. 서명·도장·음성과 호흡의 유사성은 책임·동일인·현재 생존 확정이 아니다. 마지막 위치 질문 뒤의 답이나 새 사건을 덧붙이지 않는다.
- 실제 녹음 시간은 녹음 후 확인. 현재 10분은 편집 시간표 기준이다.

- [03 이미지 프롬프트](이미지/03_10분_성문동과_두번째통화_프롬프트.md): C01~C12 독립 복사용 12개. 매 컷 3840x2160 16:9 정지 이미지, cinematic realistic Korean mystery romance, 느린 팬·줌·페이드, no readable text/logo/watermark를 명시.
- [컷목록](시나리오/컷목록.md): C01~C12 누적 시간표와 원문 근거를 추가.
- 005의 도장·3월 17일 표기 출입대장, 006의 박명희 명의 계좌·두 번째 통화, 007의 아버지와 도현 사이 원본 전달 증언·화재 관련 남성 발언, 008의 공식 기록·개인 보안회선·대리인 요청을 원문 순서로 반영.
- 화면과 발화에서 책임·생존·발화자 동일인 여부·문서 진위를 확정하지 않는다. 서윤서 외형을 고정하고 강도현 얼굴·사진·회상 얼굴을 금지한다.

## 04화 10분 패키지 — 보안회선과 삭제된 카메라

- [04 완성 각색](시나리오/04_10분_보안회선과_삭제된_카메라각색.md): 웹소설 009~012 원고 전체를 읽고 순서대로 각색, D01~D12 12컷, 00:00~10:00, 실제 발화 3,462자.
- [04 이미지 프롬프트](이미지/04_10분_보안회선과_삭제된_카메라_프롬프트.md): D01~D12 독립 복사용 12개. 모든 프롬프트에 3840x2160 16:9 정지 이미지, cinematic realistic Korean mystery romance, 느린 팬·줌·페이드, no readable text/logo/watermark, 서윤서 외형 고정, 강도현 얼굴·사진·회상 얼굴 금지를 명시.
- [컷목록](시나리오/컷목록.md): D01~D12 누적 시간표와 009~012 원문 근거를 추가.
- 009는 개인 보안회선 핸드셰이크와 성문동 기록 서버 접속, 010은 CCTV 삭제 목록과 어머니 이니셜과 일치하는 `SY-03` 계정, 011은 두 위임장과 윤서 수신자, 012는 내부 고발 기록 누락과 원본 전달 고백 순서로 구성.
- 화면과 발화는 회선 사용자·발신지, CCTV 삭제자·영상 내용, 어머니의 계정 사용, 두 위임장의 진위·효력, 내부 고발 기록의 내용·책임, 원본 소재·화재 책임을 확정하지 않는다.
- 실제 발화량은 시나리오의 `**발화**` 구간에서 화자 표기와 줄바꿈을 제외해 3,462자로 집계했다. 10분은 12컷×50초의 편집 시간표다.
