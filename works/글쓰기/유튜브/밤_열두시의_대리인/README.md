# 《밤 열두 시의 대리인》 유튜브팀

소설팀의 웹소설 001화 「대리인의 첫 밤」을 각색한 약 5분 분량 이미지컷 중심 영상 패키지다. 이 파일럿은 총 24부작 3막 중 1막 1화에 해당한다. 영상은 정지 이미지를 느린 팬·줌·페이드로 연결하고, 낭독과 효과음으로 장면의 빈틈을 채운다.

## 제작 기준

- 정지 이미지 8컷, A01~A08
- 모든 컷은 3840x2160, 16:9 가로
- cinematic realistic Korean mystery romance
- 이미지 안의 읽을 수 있는 글자·로고·워터마크 금지
- 편집은 느린 팬·줌·페이드 중심
- 낭독 대사는 약 5분 기준 1,500~2,000자

- 실제 녹음 시간은 녹음 후 확인. 현재 10분은 편집 시간표 기준이다.
