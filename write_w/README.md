# write_w — 블로그 콘텐츠 아카이브

블로그·CMS에 바로 업로드할 수 있는 마크다운 포스팅과 전용 이미지를 모아둔 폴더입니다.

## 폴더 구조

```
write_w/
├─ 2026-09-11_AI-LLM-최신동향.md   단독 인사이트 아티클
├─ series/            AI 인물열전 (20편) + 이미지 100장
├─ series2_AI부업/     AI 부업 열전 (10편) + 이미지 50장
├─ series3_TMI/        알아도 쓸모없는 신기한 지식 (10편)
├─ series4_상담소/      AI 시대 직장인 생존 상담소 (10편)
└─ series5_비교/        그래서 뭐가 다른데 (10편)
```

## 시리즈별 형식

포스팅마다 독자를 붙잡는 방식이 다르기 때문에, 시리즈마다 글의 구조 자체를 다르게 설계했습니다.

| 시리즈 | 형식 | 후킹 포인트 |
| --- | --- | --- |
| **AI 인물열전** | 리뷰형 — 캐릭터 비유 → 특장점 3가지 → 추천/비추 → 별점 | AI 도구를 사람에 빗대 캐릭터로 소비하게 만듦 |
| **AI 부업 열전** | 리뷰형 + 리스크 고지 — 이게 되는 이유 3가지 → 솔직한 리스크 → 별점 | 장점만 늘어놓는 부업 글 사이에서 "솔직함"으로 차별화 |
| **알아도 쓸모없는 신기한 지식** | 훅 선행형 — 충격적인 한 문장 → 짧은 호흡의 반전 → 자폭 엔딩 | 첫 문장에서 스크롤을 멈추게 만드는 구조 |
| **직장인 생존 상담소** | Q&A 상담형 — 사연 → 진단과 처방 → 한 걸음 더 → 맺음말 | 남의 고민을 훔쳐보는 재미 + 내 얘기 같은 공감 |
| **그래서 뭐가 다른데** | 비교형 — 한 줄 정의 → 결정적 차이(표) → 헷갈리는 지점 → 판정 | "나도 헷갈렸는데"라는 공감과 검색 수요 |

## 이미지

- `series/images/`, `series2_AI부업/images/` 에 포스팅 전용 이미지가 들어 있습니다.
- 구성: 대표 썸네일(1600×900) 1장 + 본문 카드(1200×1200) 3장 + 총평 카드(1600×1200) 1장 = **편당 5장**
- 제작 방식: HTML/CSS로 디자인해 헤드리스 Chromium으로 렌더링했습니다. 본문 마크다운에서 상대 경로로 연결되어 있어, 폴더째 옮기면 이미지도 함께 표시됩니다.
- 브랜드 로고는 오픈소스 아이콘 패키지(simple-icons, @lobehub/icons-static-svg)의 SVG를 사용했습니다. 각 상표의 권리는 해당 기업에 있으며, 리뷰·비평 목적으로 사용했습니다.

## 콘텐츠 작성 원칙

이 아카이브의 글은 아래 기준을 지켜 작성했습니다.

1. **지어낸 수치를 쓰지 않는다** — 출처를 댈 수 없는 통계·설문·매출 숫자는 쓰지 않습니다. 이 환경은 외부 웹 접속이 차단되어 실시간 사실 확인이 불가능하므로, 확실하지 않은 내용은 단정하지 않고 범위로 서술하거나 아예 제외했습니다.
2. **불리한 정보를 숨기지 않는다** — 특히 부업 시리즈는 플랫폼 약관 리스크, 경쟁 포화, 수익화까지 걸리는 기간을 함께 적었습니다.
3. **별점은 수익이 아니라 현실성** — 부업 시리즈의 별점은 "진입 난이도 대비 현실성"이며 특정 수익을 보장하지 않습니다.
4. **법률·의료·세무는 단정하지 않는다** — 제도는 개정되므로 시행 시점 기준 확인을 안내합니다.

## 사용 방법

각 `.md` 파일을 블로그 편집기에 붙여넣으면 됩니다. 이미지는 `images/` 폴더와 함께 업로드하거나, 마크다운의 이미지 경로를 업로드한 CDN 주소로 바꿔주세요.
