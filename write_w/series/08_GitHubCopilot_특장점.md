# [AI 인물열전 #8] GitHub Copilot — 옆자리에서 계속 자동완성 쳐주는 페어프로그래머

*시리즈: 전세계 AI 특장점 열전 | 8/5 | 오늘의 주인공: GitHub Copilot (Microsoft/OpenAI)*

---

## 한 줄 소개

전 세계 코드가 모여있는 GitHub에 아예 눌러앉아 사는 AI. IDE 안에서 실시간으로 코드를 자동완성해주는 원조 '코딩 페어프로그래머'.

## 이 녀석은 이런 애다

비유하자면 Copilot은 **키보드를 같이 두드리는 조용한 짝꿍**이다. 채팅창을 오가며 대화하기보다, 그냥 코드를 치기 시작하면 "어, 이거 이렇게 하려는 거지?"하며 다음 줄을 슥 채워준다. 말은 적지만 타이핑 속도는 진짜 빠르다.

## 특장점 3가지

**1. IDE에 완전히 녹아든 워크플로우**
VS Code, JetBrains 등 개발자가 실제로 코드를 짜는 그 화면 안에서 바로 작동한다. 맥락 전환(창 갈아타기) 없이 타이핑하는 흐름 그대로 도움을 받을 수 있다는 게 최대 강점.

**2. 반복 패턴 자동완성의 압도적 편의성**
보일러플레이트 코드, 테스트 케이스, 흔한 패턴은 몇 글자만 쳐도 알아서 완성해준다. "이거 손으로 다 치기 귀찮은데" 싶은 순간을 제일 먼저 캐치하는 녀석.

**3. GitHub·레포지토리 생태계와의 연결성**
실제 레포지토리 맥락(이슈, PR, 코드베이스 구조)을 참고해 제안하는 기능까지 발전하면서, 단순 자동완성을 넘어 '이 프로젝트를 이해하고 있는 동료'에 가까워지고 있다.

## 이럴 때 쓰면 좋다

- 반복적인 코드 패턴, 테스트, 보일러플레이트를 빠르게 쳐내야 할 때
- IDE를 벗어나지 않고 그 자리에서 바로 코딩 도움을 받고 싶을 때
- 기존 GitHub 워크플로우(PR, 이슈)에 자연스럽게 AI를 녹이고 싶을 때

## 이럴 땐 살짝 비추

- 처음부터 끝까지 대화하며 설계를 논의하고 싶은 작업 (이럴 땐 채팅형 AI가 더 편함)
- 코드 외의 문서·기획 작업이 주 업무일 때

## 한 줄 총평

**"말없이 옆에서 타자만 도와주는데, 그게 은근히 제일 큰 도움이 되는 동료."**

⭐️⭐️⭐️⭐️ (4.2/5) — 코딩 흐름 방해 없는 자동완성 최강자, 대화형 설계 논의는 약함.
