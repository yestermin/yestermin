# 14. IP 주소 — 택배가 정확히 찾아오는 이유

---

온라인 게임 중에 누가 "너 IP 주소 따간다"고 겁주는 말을 듣고 괜히 불안했던 적 있으신지.

IP 주소는 인터넷에 연결된 기기마다 붙는 숫자 주소다. 데이터가 엉뚱한 곳이 아니라 정확한 목적지로 배달되게 해주는 식별자다.

## 택배가 정확히 찾아오는 원리

택배기사가 물건을 문 앞까지 정확히 가져다 놓을 수 있는 건 주소가 있어서다. 도시, 동, 번지, 호수까지 정해져 있으면 전국 어디서 보내도 그 집으로 간다. 인터넷에서 이 역할을 하는 게 IP 주소다. 어떤 데이터를 보낼 때, 그 데이터에는 "이 주소로 가라"는 표가 붙는다. 중간의 여러 장비들이 이 주소만 보고 다음 방향을 정해 계속 전달한다.

집 주소에도 아파트 단지 대표 주소와 그 안 개별 세대 주소가 있듯, IP 주소도 두 겹으로 쓰이는 경우가 흔하다. 집이나 사무실 공유기는 인터넷에다 대표 주소(공인 IP) 하나로 나서고, 그 안에 연결된 노트북과 스마트폰과 스마트TV는 공유기가 나눠준 내부 주소(사설 IP)를 각각 쓴다. 밖에서 보면 한 집에서 온 우편물처럼 보이지만, 안에서는 누구 앞으로 온 건지 공유기가 다시 나눠준다.

이 주소는 대개 고정돼 있지 않다. 통신사가 가입자에게 필요할 때마다 다시 나눠주는 방식(유동 IP)이 흔해서, 공유기를 재시작하면 주소가 바뀌는 경우가 많다. 이사 갈 때마다 우편함 번호가 새로 배정되는 것과 비슷하다.

## 실제로 겪어본 장면들

특정 사이트에 접속했을 때 자동으로 한국어 화면이 뜨는 건 IP 주소로 대략적인 국가를 짐작해서다. 해외 드라마 사이트가 "이 지역에서는 이용할 수 없습니다"라고 막는 것도 같은 방식이다. 공유기를 껐다 켜면 인터넷이 다시 잡히는 것도, 통신사로부터 새 주소를 받아오는 과정이 들어 있어서다.

## 흔히 잘못 아는 것

IP 주소만 알면 그 사람 집 주소나 신원이 바로 특정된다는 생각은 과장이다. IP 주소로 알 수 있는 건 대개 대략적인 지역이나 통신사 정도다. 정확한 명의자까지 확인하려면 통신사가 가진 가입자 정보와 대조해야 하고, 이건 보통 수사기관의 요청과 절차를 거쳐야 하는 일이다. "IP 딴다"는 말이 주는 위협감에 비해 실제로 알아낼 수 있는 정보는 제한적인 경우가 많다.

IP 주소가 한 번 정해지면 평생 그 기기 것이라는 생각도 사실과 다르다. 공유기가 재시작되거나 통신사 사정에 따라 주소는 얼마든지 바뀐다. 반대로 서버처럼 항상 같은 주소를 써야 하는 경우엔 고정 IP를 따로 신청해서 쓴다.

## 함께 알아두면 좋은 말

| 용어 | 뜻 |
| --- | --- |
| 공인 IP / 사설 IP | 아파트 대표 주소와 그 안 세대별 주소 |
| 도메인 | 이 숫자 주소를 사람이 외우기 쉬운 이름으로 바꾼 것 |
| 포트 | 같은 주소 안에서 어느 프로그램으로 갈지 나누는 번호 |
| 라우터(공유기) | 주소를 보고 다음 길을 정해 데이터를 넘겨주는 장비 |

주소가 있다고 해서 그 집 안에 누가 사는지, 무슨 일을 하는지까지 다 알 수 있는 건 아니다. IP 주소도 딱 그만큼만 알려준다. 거기까지 가는 길, 그 이상은 아니다.
