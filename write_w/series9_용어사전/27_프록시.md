# 27. 프록시 — 대신 물어봐 주는 심부름꾼

---

학교나 회사 와이파이에서 유독 어떤 해외 사이트만 느리거나 아예 안 열려서, 누군가 "프록시 한번 켜봐"라고 알려준 적 있으신지.

프록시는 내가 보낼 요청을 대신 받아 목적지에 전달하고, 돌아온 응답을 다시 나에게 넘겨주는 중간 대리인 서버다.

## 가게에 직접 가는 대신 심부름꾼을 보내는 것

가게에 직접 가는 대신 심부름꾼에게 부탁하는 상황을 떠올려보자. 가게 주인은 나를 본 적이 없다. 주인이 마주하는 건 심부름꾼뿐이고, 물건 값을 치르는 것도 물건을 받아 오는 것도 그 심부름꾼이 한다. 프록시가 이 심부름꾼 역할이다. 내가 어떤 사이트에 접속하려 하면, 프록시 서버가 대신 그 사이트에 접속해서 응답을 받아온 뒤 나에게 전달해준다. 사이트 쪽에서 보면 접속해온 게 나라는 사람이 아니라 심부름꾼, 즉 프록시 서버로 보인다.

다만 심부름꾼은 봉인된 택배 상자를 통째로 감싸는 게 아니라, 부탁받은 심부름 하나를 대신 처리해주는 쪽에 가깝다. 봉투 안을 뜯어보려면 얼마든지 뜯어볼 수 있는 사람이다. 그래서 VPN이 통신 전체를 암호화된 터널로 감싸 시스템 단위로 작동하는 것과 달리, 프록시는 대체로 특정 프로그램이나 브라우저 단위로 설정되고, 오가는 내용 자체를 암호화하지는 않는 경우가 많다. 감추는 건 주로 "누가 요청했는가"이지, "무슨 내용을 주고받았는가"가 아니다.

## 실제로 일 시키는 자리

데이터를 모으는 프로그램이 한 사이트에 짧은 시간 안에 너무 자주 접속하면 그 사이트가 IP 주소를 차단해버리는 경우가 있는데, 여러 프록시를 번갈아 쓰면서 매번 다른 곳에서 온 것처�//처럼 보이게 만드는 게 흔한 회피법이다. 회사 네트워크에서는 프록시 서버 하나를 모든 직원이 거치게 해두고, 어떤 사이트는 막고 어떤 트래픽은 기록해두는 용도로도 쓴다. 반대로 서비스를 운영하는 쪽이 서버 앞단에 프록시를 세워, 밀려드는 요청을 여러 서버로 나눠 처리하게 하는 경우(리버스 프록시)도 있다.

## 흔히 잘못 아는 것

프록시와 VPN을 같은 것으로 묶어 말하는 경우가 많은데, 감싸는 범위와 방식이 다르다. VPN은 기기에서 나가는 모든 통신을 암호화된 하나의 통로로 통째로 감싼다. 프록시는 보통 특정 프로그램이나 특정 요청만 대신 처리해주고, 암호화까지는 하지 않는 경우가 흔하다. 익명성이나 보안을 더 강하게 원한다면 프록시보다 VPN 쪽이 대체로 더 적합하다.

프록시를 쓰면 무조건 익명이 된다는 생각도 틀렸다. 심부름꾼이 내가 무엇을 부탁했는지 다 알고 있듯, 프록시 서버 운영자도 내 요청 기록을 들여다볼 수 있는 위치에 있다. 어떤 곳에서 운영하는 프록시인지 모르고 쓰는 건 VPN과 똑같은 위험을 안고 있다.

프록시가 차단 우회를 위해서만 쓰인다는 생각도 좁은 이해다. 기업 네트워크에서는 오히려 감시와 필터링, 캐싱을 위한 도구로 프록시가 흔히 쓰인다. 우회 목적과 정반대의 목적으로도 같은 기술이 쓰이는 셈이다.

## 함께 알아두면 좋은 말

| 용어 | 뜻 |
| --- | --- |
| VPN | 통신 전체를 암호화된 하나의 통로로 감싸는 방식. 프록시보다 감싸는 범위가 넓다 |
| 리버스 프록시 | 서버 앞단에 세워 요청을 나눠 받는 프록시. 로드밸런서와 역할이 겹친다 |
| IP 차단 | 특정 주소에서 오는 요청을 막는 조치. 프록시가 흔히 피해 가려는 대상 |
| 캐시 | 프록시가 자주 요청되는 응답을 미리 저장해두는 방식 |

심부름꾼은 가게 앞에서 내 얼굴을 가려주지만, 내가 무엇을 부탁했는지까지 잊어주지는 않는다. 누구를 심부름꾼으로 세우느냐가, 그래서 프록시를 쓸 때 가장 먼저 따져볼 질문이다.
